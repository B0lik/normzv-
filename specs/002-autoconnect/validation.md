# Проверки 0.2.0

## Автоматические
39 тестов: DSP, legacy-формат getUserMedia, жизненный цикл потока, список доменов и поддоменов, защита от похожих доменов, off/all/selected, отсутствие повторного захвата, denied activeTab, отсутствие повторных попыток после отказа, ручная пауза, остановка только auto-owned сессий, смена сайта, сон worker, очистка вкладки, native fullscreen окно и восстановление состояния, ручной F11, окна фоновых вкладок, ошибки windows.update. Интеграционный тест подтверждает, что fullscreen-события не создают новый аудиопоток.

Статическая проверка: MV3 / Chrome 116; пять разрешений activeTab, tabCapture, offscreen, storage, tabs; host_permissions отсутствуют; точки входа, импорты и синтаксис 9 JS-файлов.

ZIP rovny-zvuk-0.2.0.zip проверен: 13 файлов расширения, manifest версии 0.2.0 в корне, модули automatic/fullscreen включены; макет API и demo не включены.

## Интерфейс
Настоящие popup.html / popup.js / popup.css открыты в Chromium-движке встроенного браузера с отдельным макетом Chrome API, не включаемым в ZIP. Проверены включение/выключение авто, all/selected, добавление сайта по URL и удаление, ручная пауза, повторное включение, сохранение после перезагрузки страницы. Ошибок консоли нет. Снимок: artifacts/autoconnect-panel.png.

## Ограничения
Автоподключение не обходит обязательный per-tab вызов расширения, предусмотренный Chrome. Для новой вкладки нужно открыть значок расширения; при навигации на другой сайт может потребоваться повторный вызов. Это явно указано в UI и README.

Fullscreen исправляет соответствующий отчёту пользователя режим fullscreen-within-tab через windows.update; логика подтверждена тестами макетов и исходником Chromium. Нативное окно пользовательского Chrome, YouTube и другой внешний плеер после обновления в этой среде не проверены. Сохранение аудио и отсутствие адресной строки/панели задач требуют проверки пользователем на сайтах.

DSP не менялся; прежняя браузерная проверка алгоритма остаётся применимой. Не заявляется новая end-to-end проверка Chrome или сертификация всех плееров.
