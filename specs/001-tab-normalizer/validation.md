# Validation / Convergence

Дата: 2026-10-03. Версия: 0.1.0.

## Исправление 0.1.1
- По отчёту пользователя 0.1.0 не запускалась на YouTube и другом видеоплеере: Chrome отклонял смешение legacy mandatory и современных ограничений getUserMedia.
- Регрессионный тест с проверкой формата воспроизвёл ровно Malformed constraint до исправления. В 0.1.1 оставлен совместимый legacy audio.mandatory по официальному примеру Chrome.
- Полный набор после исправления: 18 passed, 0 failed; статические проверки прошли. Новый ZIP содержит версию 0.1.1.
- DSP не менялся: браузерный smoke ниже относится к первоначальной проверке того же алгоритма. Реальный захват сайтов после исправления требует повторной проверки в пользовательском Chrome.

## Проверено
- Node 24.19.0: 17 тестов, 17 passed, 0 failed.
- AC1: сильный режим, синус 440 Hz с входным RMS −42/−30/−18/−6 dBFS → установившийся RMS около −19,89 dBFS; разброс менее 0,001 dB в Node.
- AC2: резкий скачок после усиления тихого сигнала, импульсы амплитудой 4, частоты 44,1/48/96 kHz: ни один выходной сэмпл не выше −1 dBFS (с допуском float32).
- AC3: тишина, шум ниже порога, стерео с отношением каналов 4:1, недопустимые настройки и NaN, регулировка уровня на работающем DSP.
- AC4–AC5: тесты макетов Chrome API и аудиопотоков: повторный старт, независимые вкладки, сон/пересоздание worker, ошибки старта, processorerror, завершение трека, suspended AudioContext, сохранение/передача настроек, отключение, освобождение потока после таймаута старта. Это не end-to-end проверка Chrome API.
- Manifest V3, minimum Chrome 116, четыре заявленных разрешения, точки входа, импорты, синтаксис всех JS расширения проверены.
- Настоящий AudioWorklet в Chromium-движке встроенного браузера Codex, локальная HTTP-страница, старт кнопкой: **PASS**, 48 kHz, выход −19,89 / −19,89 / −19,89 dBFS, разброс **0,005 dB**, максимальный пик **−1,00 dBFS**. Данные получены через MessagePort из реального аудиопотока; вывод теста беззвучный.

## Границы проверки
- Обычный Chrome не подключён к доступному браузерному управлению. Расширение не установлено в личный профиль пользователя.
- Реальный tabCapture → offscreen, browser badge, длительная работа при сне worker, навигация и внешние плееры требуют ручной проверки после установки по README.
- DRM/защищённый звук, аппаратные устройства вывода, LUFS/true-peak и перцептивные проверки речи/музыки не сертифицированы.
- AC6: поставляется готовая папка без сборки, ZIP и README с проверками после установки. Архив проверен: 10 файлов, manifest.json в корне, аудиомодули и настройки включены.

## Convergence
Исходные требования реализованы в пределах первой версии. Автоматических дефектов и незакрытых задач реализации не обнаружено. Проверка работы на внешних плеерах остаётся явно обозначенным ограничением верификации, а не утверждением совместимости.
