# Исправление запуска захвата — 0.1.1

## Goal
Устранить Malformed constraint при включении на YouTube и других плеерах.

## Existing Context
В extension/offscreen.js legacy audio.mandatory для chromeMediaSource смешан с современными audio.echoCancellation/noiseSuppression/autoGainControl. Пользователь получил ошибку парсинга getUserMedia до запуска DSP.

## Requirements
Один совместимый формат ограничений, захват только аудио указанной вкладки, обновлённые устанавливаемые файлы и ZIP.

## Assumptions
Отчёт пользователя достаточен для локализации; внешние сайты не нужны для проверки формата. Реальный захват на сайтах требует повторной пользовательской проверки после перезагрузки расширения.

## Technical Plan / Ordered Tasks
1. Научить макет getUserMedia отклонять смешение legacy и современных ограничений; воспроизвести сбой тестом.
2. Оставить audio.mandatory с chromeMediaSource и chromeMediaSourceId по официальному примеру Chrome, убрать соседние современные ограничения.
3. Проверить тесты и manifest, обновить версию, инструкцию и архив.

## Validation / Definition of Done
Регрессионный тест воспроизводит ошибку до исправления и проходит после; полный набор проверок проходит. Готова версия 0.1.1, пользователь может обновить её без переустановки из папки extension.

Источник: https://developer.chrome.com/docs/extensions/how-to/web-platform/screen-capture

## Результат
Регрессия воспроизведена до исправления; после исправления все 18 тестов и статические проверки проходят. Архив rovny-zvuk-0.1.1.zip проверен: версия 0.1.1 и исправленный offscreen.js включены, всего 10 файлов. Реальная повторная проверка сайтов пользователем пока не выполнена.
