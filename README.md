# Ровный звук — расширение Chrome

Версия 0.2.1 нормализатора громкости для звука вкладки. Тихие фрагменты усиливаются, громкие ослабляются, резкие пики ограничиваются. Работает с суммарным звуком вкладки, поэтому не привязана к конкретному видеоплееру. Есть автоподключение для всех или выбранных сайтов и поддержка полного экрана при захвате звука.

## Установить

Нужен настольный Chrome версии 116 или новее.

Если скачиваете проект с GitHub, нажмите **Code → Download ZIP** и распакуйте архив. На шаге 4 выберите папку **extension** внутри распакованного проекта. В локальной рабочей копии ниже используется путь `C:\normzv\extension`; у вас он может отличаться.

1. Откройте `chrome://extensions` в Chrome.
2. Включите **Режим разработчика** справа сверху.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку **`C:\normzv\extension`**. Именно её: внутри лежит `manifest.json`.
5. Закрепите **Ровный звук** через меню расширений (значок пазла).

Для переноса на другой компьютер можно использовать отдельно подготовленный архив `dist/rovny-zvuk-0.2.1.zip`: распакуйте его и выберите полученную папку на шаге 4. Каталог dist не хранится в Git; из GitHub устанавливайте папку extension, как описано выше. ZIP напрямую в Chrome не загружается. Сборка и установка зависимостей не нужны.

### Обновить установленное расширение до 0.2.1

Если расширение загружено из `C:\normzv\extension`, файлы уже обновлены. На `chrome://extensions` нажмите кнопку **Перезагрузить** (круговая стрелка) на карточке **Ровный звук**, затем **обновите вкладку с видео** и снова включите обработку. Перезагрузка расширения завершает старый захват. Если прежний интерфейс сохраняется, выключите расширение и включите снова. Новое разрешение **scripting** нужно для временного обработчика полного экрана на вкладке, где вы вызвали расширение; постоянный доступ ко всем сайтам не запрашивается. Если устанавливали из другой папки, сначала замените её содержимое файлами из нового ZIP.

В 0.1.1 исправлена ошибка `Malformed constraint` при запуске захвата: убрано смешение legacy `mandatory` и современных параметров `getUserMedia`.

## Пользоваться

Откройте видео или аудио на обычном сайте, нажмите значок расширения и **Включить для вкладки**. Режим **Сильно** выбран по умолчанию: он лучше всего сближает тихие и громкие фрагменты. Регулятор **Итоговая громкость** задаёт желаемый уровень звука; громкость компьютера продолжает работать отдельно.

Закройте окно расширения — обработка продолжается. Метка **ON** на значке означает, что звук этой вкладки обрабатывается. Настройки режима и уровня общие для всех включённых вкладок. При выключенном авто для другой вкладки используйте ручную кнопку.

**Отключить для вкладки** завершает захват и возвращает обычный звук. При включённом авто это также приостанавливает автоподключение для данной вкладки: следующие события воспроизведения не включат её обратно. Кнопка **Включить для вкладки**, выключение/повторное включение авто или смена сайта снимают эту паузу. При закрытии вкладки её обработка завершается.

## Автоподключение

Включите переключатель **Автоподключение** и выберите область:

- **Все сайты:** все веб-вкладки со звуком, где Chrome разрешил захват.
- **Выбранные:** только сайты из списка. По умолчанию в нём `youtube.com` и `youtu.be`, включая поддомены YouTube. Оставьте этот список для режима «только YouTube».

Чтобы добавить сайт, введите домен или полный адрес и нажмите **Добавить**, либо используйте **Добавить текущий сайт**. Кнопка **×** удаляет сайт. Список и переключатель сохраняются после перезапуска Chrome. Пустой список в режиме **Выбранные** не подключает ни один сайт.

Chrome не позволяет расширению самостоятельно начать захват новой вкладки без вызова пользователем. Поэтому **в каждой новой подходящей вкладке нажмите значок расширения один раз**: при включённом авто обработка начнётся при открытии окна расширения, отдельная кнопка включения не нужна. Затем обработка продолжается в фоне и может переподключаться по событиям воспроизведения. После перехода на другой сайт Chrome может потребовать повторное нажатие. Если доступ ещё не выдан, на значке появляется **!**, а обработка не объявляется включённой.

Выключение переключателя останавливает автоматически запущенные вкладки. Вкладки, которые были включены вручную, продолжают работать и отключаются отдельной кнопкой. Удаление сайта или переход с **Все сайты** на **Выбранные** прекращает автоматическую обработку исключённых сайтов.

## Полноэкранный режим

При активном захвате Chrome иногда разворачивает плеер только внутри вкладки, оставляя адресную строку и панель задач. Расширение переводит окно активной вкладки в настоящий fullscreen, не перезапуская звук. **Для выхода нажмите ту же кнопку полного экрана плеера ещё раз или Escape.** Возвращается прежнее normal/maximized окно; нормализация продолжает работать. Это также работает с клавишей полного экрана самого плеера, если она переключает стандартный Fullscreen API.

В 0.2.1 выход отслеживается напрямую через `fullscreenchange` верхнего документа, в том числе для плеера во вложенном iframe. Escape дополнительно запрашивает выход, не отменяя обработчики клавиатуры сайта. Задержанный сигнал tabCapture проверяется по актуальному состоянию документа и не должен развернуть вышедший плеер обратно. Задержанное событие размеров окна также не сбрасывает сохранённое состояние. При недоступности временного доступа к странице остаётся резервный сигнал tabCapture. При остановке обработки или переключении вкладки возвращается прежнее окно. Окна, уже развёрнутые пользователем до включения полного экрана плеера, расширение не сворачивает.

Исправление рассчитано на стандартный Fullscreen API; режим только через CSS или запрет полного экрана самим сайтом требуют отдельной проверки. После обновления проверьте кнопку входа и выхода и Escape на YouTube и втором плеере.

Для выравнивания между разными видео держите регулятор громкости самого плеера на стабильном уровне. Если он установлен в ноль или вкладка заглушена, расширению нечего усиливать.

## Что ожидать

- **Сильно:** максимальное выравнивание, речь и тихие фрагменты заметнее; музыкальная динамика сглаживается сильнее.
- **Средне:** компромисс между ровной громкостью и сохранением динамики.
- **Мягко:** небольшое сглаживание с более заметными перепадами.
- Короткие переходы остаются: алгоритм реагирует плавно, усиление тихого фрагмента устанавливается примерно за доли секунды — секунду.
- Паузы остаются паузами; усиление ограничено, чтобы не бесконечно поднимать шум. Фоновый шум внутри тихой речи тоже может стать слышнее.
- Это RMS-нормализация с ограничителем сэмпловых пиков, а не точный измеритель LUFS или true-peak. Громкость разных тембров на слух может отличаться.
- Одновременные источники в одной вкладке обрабатываются вместе: голос и музыку из готовой звуковой дорожки расширение не разделяет.
- Добавляется 5 ms задержки ограничителя плюс задержка аудиозахвата и браузера. На защищённом контенте, отдельных DRM-плеерах и служебных страницах обработка может быть недоступна.

## Проверить после установки

1. Запустите видео с перепадами громкости. Включите **Сильно**: индикаторы входа и выхода должны двигаться, а разница между тихими и громкими фрагментами уменьшиться.
2. Закройте окно расширения на 30 секунд, затем откройте снова. Статус должен остаться включённым.
3. Переключите качество видео, перейдите к другому ролику, проверьте полноэкранный режим. Если захват завершился, включите снова.
4. Нажмите **Отключить для вкладки**: исходный звук должен продолжить воспроизводиться.
5. Повторите на втором сайте и, при необходимости, на двух вкладках одновременно. Каждая включается и выключается отдельно.
6. Включите авто в режиме **Выбранные** с YouTube: при открытии расширения на YouTube обработка должна включиться сама; на другом сайте — остаться выключенной. Перейдите на **Все сайты** и проверьте второй сайт.
7. Нажмите кнопку полного экрана плеера: адресная строка и панель задач должны скрыться, а нормализация продолжить работать. Нажмите **эту же кнопку повторно**: окно должно вернуться к прежнему размеру. Войдите ещё раз и выйдите через **Escape**. Повторите несколько раз и проверьте, что метка ON и звук сохраняются. Выключите авто: автоматические вкладки должны остановиться.

Если при включении пропал звук, выключите обработку. Если popup недоступен, отключите расширение на `chrome://extensions`, затем включите снова. Другие расширения, захватывающие ту же вкладку, могут конфликтовать.

## Приватность

Всё аудио обрабатывается локально в оперативной памяти. Расширение не записывает аудиофайлы, не обращается к серверу и не запрашивает микрофон. Локально сохраняются настройки громкости и автоподключения и список выбранных доменов. В памяти браузерной сессии хранятся паузы и состояние управления окнами. Разрешение **tabs** даёт доступ к адресам и признаку звучания открытых вкладок, чтобы выбирать сайты; отдельного доступа к истории посещений нет. **scripting + activeTab** устанавливают временный наблюдатель полного экрана в верхнем документе захваченной вкладки. Он читает только наличие fullscreenElement и клавишу Escape, не читает текст/формы страницы и не меняет разметку плеера. Постоянные host_permissions не запрашиваются. Chrome может показывать индикатор захвата звука вкладки — это часть механизма обработки.

## Разработка и проверка

Нужен Node.js 22+ только для разработки, для установки расширения Node не нужен.

```powershell
cd C:\normzv
npm test
npm run check
npm run demo
```

Откройте `http://127.0.0.1:8765` для беззвучного теста настоящего AudioWorklet и тестового тона с меняющейся громкостью. Тон включается вручную. Для прослушивания начните с небольшой системной громкости.

`http://127.0.0.1:8765/demo/popup-preview.html` показывает настоящий интерфейс с имитацией Chrome API. Это проверка интерфейса, а не реального захвата или fullscreen окна Chrome.

`http://127.0.0.1:8765/demo/fullscreen-test.html` проверяет настоящий Fullscreen API, рабочий наблюдатель и iframe другого origin. Нажмите одну и ту же кнопку для входа/выхода либо Escape. Состояние окна Chrome имитируется; звука и реального tabCapture в этой проверке нет.

- `extension/` — готовая папка расширения.
- `tests/` — проверки DSP и управления сессиями с макетами Chrome API.
- `specs/001-tab-normalizer/` — требования, план, задачи и результаты проверки.
- `specs/002-autoconnect/` — автоподключение, исправление полного экрана и результаты проверки.

49 автоматических тестов прошли, включая выход кнопкой/Escape без события захвата, задержанные события, восстановление окна после сна worker, отсутствие перезапуска звука и отказ инъекции. Проверен браузерный Fullscreen API с настоящим наблюдателем: одна кнопка входа/выхода, Escape и кнопка cross-origin iframe; ошибок консоли нет. Состояние окна в этой проверке имитировалось. Ранее выполненный браузерный DSP smoke для неизменённого алгоритма при 48 kHz прошёл: разброс уровней 0,005 dB, пик −1 dBFS. Пользователь подтвердил корректную работу расширения после обновления до 0.2.1. Подробности: `specs/002-autoconnect/fix-fullscreen-exit.md`.

Основа API: [официальный пример фонового захвата Chrome](https://developer.chrome.com/docs/extensions/how-to/web-platform/screen-capture), [tabCapture](https://developer.chrome.com/docs/extensions/reference/api/tabCapture), [Web Audio](https://webaudio.github.io/web-audio-api/).
